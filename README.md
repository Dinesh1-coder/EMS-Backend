# Employee Management System (EMS)

## 📌 Project Overview
The Employee Management System (EMS) is a full-stack web application developed to manage employee information efficiently. It allows users to perform basic employee management operations such as creating, viewing, updating, and deleting employee records.

## 🚀 Technologies Used
- **Frontend:** React.js, HTML, CSS, Bootstrap
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API Testing:** Postman
- **Version Control:** Git and GitHub

## ✨ Features
- Add new employee details
- View all employee records
- Update existing employee information
- Delete employee records
- REST API integration using Spring Boot
- Database connectivity with MySQL

## 🔗 API Endpoint
**Get All Employees**
```http
GET http://localhost:8081/api/employees
```

This endpoint retrieves the list of employees from the backend API while the application is running locally.

## ⚙️ How to Run the Project

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Run the Backend
- Open the Spring Boot project in your IDE.
- Configure the MySQL database connection in `application.properties`.
- Start the Spring Boot application.
- The backend runs on port `8081`, if configured that way.

### 3. Run the Frontend
- Open the frontend folder in the terminal.
- Install dependencies:
```bash
npm install
```
- Start the React application:
```bash
npm run dev
```
